# ERHC Dev Portfolio

Portafolio profesional de Edwin Huamanttupa, Backend Developer especializado en Java, Spring Boot, Oracle, APIs REST y arquitectura de software.

## Tecnologías

- Astro
- Tailwind CSS
- TypeScript
- Formspree

## Desarrollo local

```bash
npm install
npm run dev
```

## Validación

```bash
npm run build
npm run preview
```

El sitio incluye versiones en español e inglés, tema claro/oscuro, diseño responsive, proyectos, experiencia, formación y formulario de contacto.
